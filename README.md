# Rock Paper Scissors Game 🪨📄✂️

## About the Project
This is a beginner-friendly, console-based Rock-Paper-Scissors game built using Python. It lets a user play against a computer opponent with randomized selections, practicing control flow and input handling.

## Features
- **Interactive Gameplay:** Play classic Rock, Paper, Scissors against an automated computer opponent.
- **Random Choice Generation:** Uses Python's `random` module to choose the computer's move dynamically.
- **Input Cleaning:** Normalizes user input using `.strip().lower()` to handle extra spaces and capital letters.
- **Attempt Tracking:** Keeps count of total turns taken until a game-ending condition is reached.
- **Error Handling:** Identifies invalid inputs and alerts the user.

## Technologies Used
- Python 3
- `random` module (`random.choice`)
- `while` loops and control flow
- `if-elif-else` conditional statements
- String manipulation (`.strip()`, `.lower()`)
- F-string formatting

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:
   `python rock_paper_scissors.py`
   If that command doesn't work, try `python3 rock_paper_scissors.py`.
